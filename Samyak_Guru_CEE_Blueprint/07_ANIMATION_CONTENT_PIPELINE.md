# Scientific Animation and Asset Production Pipeline

## Full pipeline
Official verified syllabus → measurable objective → scientific reference collection → concept review → storyboard → asset type selection → geometry/diagram/simulation creation → scientific accuracy checks → animation and interaction rig → labels/hotspots/camera → narration/captions/accessible text → MCQ mapping → authoring export → secure quarantine upload → file scan/integrity → optimization → versioned manifest → automated validation → expert review → rights/accessibility approval → immutable publication → CDN/offline delivery → student learning events → analytics → revision backlog.

## Asset branches
- **3D anatomy:** Blender source → GLB/glTF optimized, geometry/labels validated, texture compression, node names and animation clips.
- **2D:** SVG source sanitized/rasterized as necessary; Rive/Lottie only if vetted and compatible.
- **Molecular:** trusted molecular formats, scientific validation, accurate representation.
- **Physics:** deterministic numerical engine, governing equations, unit validation, parameter bounds, idealization notices.
- **Video:** source MP4 → adaptive streaming where infrastructure supports it; captions and transcript.
- **Audio:** AAC/Opus, synchronized captions/transcripts.

## File security
Short-lived upload authorization, size/quota/type allowlist, private quarantine, magic-byte checks, malware scanning, parser isolation/timeouts, GLB external dependency checks, SVG sanitization, checksums, no public access until publication. Background workers idempotent with bounded retries/dead-letter.

## Asset package
Stable asset ID, immutable version ID, author/source license, topic/syllabus mapping, learning objectives, original project reference, runtime URL/checksum, camera presets, layer names, clips, hotspots, captions, static fallback, approved scientific sources, review decisions, compatibility flags, status and timestamps.

## Human Heart pilot scene breakdown
1. External heart orientation (major vessels).
2. Cross-sectional four chambers.
3. Valve isolation and flow direction.
4. Deoxygenated blood: body → venae cavae → right atrium → tricuspid valve → right ventricle → pulmonary valve → pulmonary artery → lungs.
5. Oxygenated blood: lungs → pulmonary veins → left atrium → mitral valve → left ventricle → aortic valve → aorta → body.
6. Cardiac cycle guided states with accurate valve positions.
7. Label-identification exercise.
8. Approved MCQ linked to scene state.
9. Error feedback and targeted revision.

Scientific accuracy warning: visual scale and anatomy may be simplified; label simplifications. Have a qualified subject expert validate structures and explanations.

## Publication gate
No published resource without verified syllabus mapping, approved scientific content, accessible alternative, content rights and asset technical validation. An edited approved asset/lesson becomes a **new draft version**.
