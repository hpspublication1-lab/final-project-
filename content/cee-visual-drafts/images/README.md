# Unreviewed images: not for students, not served

These 26 images came with the parallel build (commit `65d1768`, 23 Nov 2026), which put them
in `public/`, where anything is served to anyone with the address. Their source and licence
are not recorded; they appear to be generated illustrations. Nothing in the site uses them;
only the unreviewed draft lessons beside this folder refer to them.

They were moved here so that merging PR #6 doesn't start serving them. Before any of them is
used, it needs a recorded source and licence, then the same scientific, visual and rights
review as any visual (upload it through Admin → CEE visual lessons → Visuals). Anatomical
images in particular must be checked by the academic reviewer.

The live site (deployment `a16e0bd`) never contained them.
